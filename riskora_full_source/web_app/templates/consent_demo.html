How the simulator works

  1. Create a request for a dummy account.
  2. A six-digit test code appears once on the next page.
  3. Enter the code and choose Approve or Reject.
  4. The decision is saved in a local SQLite audit record.

Limits: code expires after five minutes; three incorrect attempts lock the request. Approved test requests permit only a scoped local dummy-data preview until expiry. Original internal staff pages remain separately role-protected; this is not real customer consent.
