# SLT Customer Payment Intelligence — Flask prototype

Flask pages: Overview, Customer Search & Profile, Creditworthiness, Collections.

Run from the **outer project root** with `python web_app/app.py`.
This prototype uses the approved synthetic workbook in `data/` and the files generated by Steps 14 and 15 in `outputs/`.

**Not suitable for deployment or real customer data**: no authentication, role-based access, security review or audit logging. Human review of all draft recommendations is mandatory.
